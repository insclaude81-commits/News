# morning-news-skill

매일 아침 기사를 직접 수집해 요약하고, **금리 · 산업 · 리스크 세 관점으로 해석한 뒤 셋이 모두 동의하는 지점까지 좁힌** 브리핑을 HTML로 발행하는 Claude Code 스킬입니다.

헤드라인 목록이 목적이 아닙니다. 그건 포털에서 30초면 봅니다. 이 스킬이 만드는 것은 **여러 기사를 다 읽은 사람만 할 수 있는 말**입니다. 서로 다른 분야의 두 사건이 사실은 같은 원인을 공유한다는 관찰, 숫자 하나가 왜 통념과 어긋나는지, 오늘의 지배적 서사가 놓치고 있는 것.

## 무엇이 나오나

하루치 산출물은 세 개입니다.

| 파일 | 용도 |
|---|---|
| `brief-YYYY-MM-DD.html` | 읽는 브리핑. 아티팩트로 발행되고 폰에서 검색·필터가 됩니다 |
| `brief-YYYY-MM-DD.md` | 기계가 읽는 아카이브. YAML 프런트매터에 그날의 섹터 상태와 금리 뷰가 들어갑니다 |
| `mail-YYYY-MM-DD.txt` | 그대로 복사해 메일로 보낼 수 있는 본문 |

`examples/` 에 실제 산출물이 들어 있습니다.

### 브리핑 구성

1. **지표 테이프** 그날의 핵심 숫자 5~7개
2. **4개 분야** AI·테크 / 경제·시장 / 국내 / 해외·국제 정세. 분야마다 판정 칩과 지표 4개, 기사 3~4건
3. **인사이트** 연결고리 2~3개, 반대편 시각 1개, 날짜가 박힌 지켜볼 것
4. **세 개의 시선** 아래 참고

### 세 개의 시선

같은 기사를 직업이 다른 세 사람이 읽으면 어떻게 갈리는지, 그리고 그럼에도 셋이 부정하지 못하는 지점이 무엇인지를 씁니다.

| | 관점 | 매일 다루는 범위 |
|---|---|---|
| **A** | 금리 | 3년물 · 10년물 · 30년물 + 커브 |
| **B** | 산업 | 로봇 / AI 인프라 / 반도체 / 2차전지 / 자동차 / 조선 / 방산 / 에너지 |
| **C** | 리스크 | 그날 가장 취약한 두 곳 |

A가 팀장으로 회의를 주재하고, 3~5라운드 토론을 거쳐 **만장일치 공통분모**를 냅니다. 여기서 중요한 건 합의만이 아닙니다. 회의록에는 **누가 무엇을 양보했는지**와 **끝까지 갈린 지점, 그리고 그것이 언제 무엇으로 판별되는지**가 함께 남습니다. 세 전문가가 합의하지 못했다는 사실 자체가 정보이기 때문입니다.

A · B · C는 실존 인물이 아니라 관점의 유형입니다. 이 스킬은 시장 해석을 쓰지 투자 권유를 쓰지 않습니다.

## 설계 원칙

**모든 시각에 무효 조건을 붙입니다.** "지켜봐야 한다"는 무효 조건이 아닙니다. "10년물이 4.2% 아래로 내려가면"이 무효 조건입니다. 틀렸다고 인정할 사건을 미리 적어두는 것이, 이 브리핑과 아무 말 대잔치를 가르는 유일한 장치입니다.

**출처를 등급으로 나눕니다.** 블룸버그 · 로이터 · AP · 워싱턴포스트 · 매일경제 · 한국경제 · 연합뉴스 같은 1급에서 먼저 찾고, 못 찾을 때만 트래픽 상위 인터넷 매체로 내려갑니다. 개인 블로그나 자동 요약 애그리게이터는 쓰지 않습니다. 페이월 기사는 스니펫으로 사실을 확인하고 본문은 접근 가능한 매체에서 읽되, 출처에 `블룸버그 (한국경제 인용)` 처럼 둘 다 적습니다.

**시세는 종가만 씁니다.** 장중에 쓰인 기사에는 그 시점의 값이 실립니다. 실제로 이 스킬은 첫날 장중 -0.23%를 종가로 착각해 "코스피가 하락했다"고 쓸 뻔했습니다. 실제 종가는 +0.88%였습니다. 그 경험이 규칙으로 들어가 있습니다.

**어제와 이어집니다.** 매일 아침 어제 `.md` 를 읽어 후속 전개를 반영하고, 섹터 상태가 뒤집히면 그 사실을 표시합니다. 뒤집힌 날이 가장 중요한 날입니다.

## 설치

```bash
git clone https://github.com/insclaude81-commits/News.git
```

Claude Code 개인 스킬 폴더로 복사합니다.

```
Windows  %USERPROFILE%\.claude\skills\morning-news\
macOS    ~/.claude/skills/morning-news/
```

그다음 `SKILL.md` 의 **설정** 절에서 `BRIEF_DIR` 한 줄을 자기 경로로 바꾸면 끝입니다.

## 사용

Claude Code에서 이렇게 말하면 실행됩니다.

```
아침 브리핑 만들어줘
```

특정 분야만 요청해도 됩니다. `AI 뉴스만 정리해줘` 처럼 범위를 좁히면 기사 수를 늘리고 인사이트와 세 개의 시선은 그대로 유지합니다.

### 매일 자동 실행

Claude Code의 예약 작업으로 평일 아침에 자동 실행할 수 있습니다. 프롬프트 예시는 [`docs/scheduled-task.md`](docs/scheduled-task.md) 에 있습니다.

## 폰에서 쓰기

발행된 아티팩트는 휴대폰 브라우저에서 그대로 열립니다.

- **상단 검색** 기사 · 인사이트 · 섹터 · 회의 발언까지 실시간 필터링, 일치 부분 형광 표시
- **헤드라인 모드** 기사 16건을 제목만 남겨 한 화면에 넣고, 탭하면 그 기사만 펼침
- **섹터 타일 접기** 좁은 화면에서 8개 섹터를 이름과 상태만 보여주고 탭하면 논거 표시
- 섹션 칩 바로가기, 읽기 진행률, 맨 위로

전부 클래스 이름만 보고 동작해서, 내용이 매일 바뀌어도 그대로 작동합니다.

## 구조

```
SKILL.md                    수집 · 요약 · 인사이트 · 세 개의 시선 절차
references/
  sources.md                출처 등급표, 분야별 검색어, 금리 데이터 소스
  desk.md                   A · B · C 페르소나 정의와 만장일치 회의 규칙
assets/
  brief-template.html       라이트/다크 대응 HTML 템플릿 + 모바일 조작 레이어
examples/
  sample-brief.html         실제 산출물
  sample-archive.md         기계가 읽는 아카이브 예시
  sample-mail.txt           메일 본문 예시
docs/
  scheduled-task.md         매일 자동 실행 프롬프트
```

## 만들면서 배운 것

스킬을 쓰면서 실제로 부딪힌 문제들이 규칙이 됐습니다.

- 장중 수치를 종가로 착각 → **마감 기사에서 종가만 쓴다**
- 한국어 검색에 작년 같은 날짜 기사가 섞여 들어옴 → **연도를 확인한다**
- 세 페르소나가 비슷한 말을 하기 시작함 → **결론이 갈리지 않으면 실패로 본다**
- 유가 상승의 수혜 섹터여야 할 2차전지가 자동차와 같이 떨어짐 → **2차전지와 자동차를 같이 묶지 않는다**

## 면책

이 스킬이 만드는 브리핑은 뉴스에 대한 해석이며 투자 자문이 아닙니다. 등장하는 A · B · C는 실존 인물이 아닌 관점의 유형입니다. 요약과 해석은 원문을 재구성한 것이므로, 판단의 근거로 삼기 전에 원문을 확인하시기 바랍니다.
